# Bottom View of Binary Tree

**Difficulty:** `Medium` | **Topics:** `Tree`, `Breadth-First Search (BFS)`, `Hash Table`

## Problem Statement

Given a binary tree, return the **bottom view** of it. The bottom view of a binary tree is the set of nodes visible when
the tree is viewed from the bottom, ordered from left to right.

If there are multiple bottom-most nodes passing through the same vertical line (Horizontal Distance), the node that
appears **last** in a standard level-order traversal is considered visible from the bottom.

### Examples

* **Example 1:**
    * **Input:** `root = [20, 8, 22, 5, 3, null, 25, null, null, 10, 14]`
      ```text
              20
            /    \
           8      22
          / \       \
         5   3       25
            / \      
           10  14
* **Output**: `[5, 10, 3, 14, 25]`
