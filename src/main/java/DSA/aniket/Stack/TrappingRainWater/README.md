# Traping Rain Water

## Problem Statement

Given `n` non-negative integers representing an elevation map where the width of each bar is `1`, compute how much water
it can trap after raining.

## Input Format

* The first line contains one integer input `n`, the size of the array.
* The second line contains `n` space-separated integers (`arr[i]`) that describe the elevation/height of each bar. *(
  Note: The problem text says "width", but in the standard context of this problem, it refers to the height/elevation of
  the bars).*

## Output Format

* Prints a single integer value, which represents the total amount of water it can hold.
