# Subarray Product Less Than K

**Difficulty:** Medium  
**Topics:** Array, Sliding Window, Two Pointers

## Problem Description

Given an array of integers `nums` and an integer `k`, return the number of contiguous subarrays where the product of all
the elements in the subarray is strictly less than `k`.

---

## Input / Output Format

**Input Format:**

* The first line contains an integer `n`, denoting the length of the array.
* The second line contains `n` space-separated integers representing the array `nums`.
* The last line contains an integer `k`.

**Output Format:**

* Return a single integer representing the number of contiguous subarrays with a product strictly less than `k`.

---

## Examples

### Example 1

**Input:**

```text
4
10 5 2 5
100
```

**Output:***

```text
8
```
