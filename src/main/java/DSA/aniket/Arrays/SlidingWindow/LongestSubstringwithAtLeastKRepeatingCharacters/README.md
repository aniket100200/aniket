# Longest Substring with At Least K Repeating Characters

**Difficulty:** Medium  
**Topics:** String, Divide and Conquer, Hash Table, Sliding Window

## Problem Description

You are given a string `str` and a number `k`. You are required to find the length of the longest substring such that
the frequency of each character in the substring is at least `k`.

---

## Input / Output Format

**Input Format:**

* The first line of the input contains the string `str`.
* The second line of the input consists of the number `k`.

**Output Format:**

* The only integer in the output represents the length of the longest substring satisfying the specified condition. If
  no such substring exists, return `0`.

---

## Examples

### Example 1

**Input:**

```text
xxxyy
3
```

**Output**

```text
3
```
